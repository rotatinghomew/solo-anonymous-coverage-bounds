# 匿名重叠统计与家长服务覆盖承诺

数据来自独立设计的合成业务记录，不含真实人员资料。文件为 UTF-8 JSON。

## 资料字典

`frames` 的分层互斥，`population` 是同期间该层基数；没有跨月身份。`certificates` 的日期是事实期间，`relation` 规定集合怎样计数，同一份上下界包含端点。单点凭证是该点总人数；多点按声明为交集或并集。`audience` 是允许使用凭证作出结论的范围；不允许合并相邻分层来推断小团体身份，也不持有可导出的家庭连接。调整计划的保底是失去原服务点独有覆盖的家庭中能够保留服务的人数；联办方确认每个补位会接住一个尚未被别处承接的家庭，但不能多于该点的独有人数。`slots` 同一席位只可被一个请求占用，`points` 表示可承接点；历史已经耗用的席位继续扣除。`new_certificate` 是独立待核来件，不覆盖同名凭证。`history` 中撤回是撤销证据用途，不是撤销服务承诺。

## 读取与核对

使用 Python 3.11。
本地虚拟环境可按 `python3 -m pip install -r requirements.txt` 安装锁定的数值工具。有隔离运行环境时可直接使用已安装版本。

用 `python3 -m json.tool data/records.json` 查看原始记录。用 `python3 -m unittest discover -s tests -v` 核对演练资料的格式及关联。仓库目前只提供资料与输入核对，不提供业务分析结果。
