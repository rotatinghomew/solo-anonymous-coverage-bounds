# 匿名重叠统计与家长服务覆盖承诺

数据来自独立设计的合成业务记录，不含真实人员资料。文件为 UTF-8 JSON。

## 资料字典

`frames` 的分层互斥，`population` 是同期间该层基数；没有跨月身份。`certificates` 的日期是事实期间，`relation` 规定集合怎样计数，同一份上下界包含端点。单点凭证是该点总人数；多点按声明为交集或并集。`audience` 是允许使用凭证作出结论的范围；不允许合并相邻分层来推断小团体身份，也不持有可导出的家庭连接。调整计划的保底是失去原服务点独有覆盖的家庭中能够保留服务的人数；联办方确认每个补位会接住一个尚未被别处承接的家庭，但不能多于该点的独有人数。`slots` 同一席位只可被一个请求占用，`points` 表示可承接点；历史已经耗用的席位继续扣除。`new_certificate` 是独立待核来件，不覆盖同名凭证。`history` 中撤回是撤销证据用途，不是撤销服务承诺。
`requirements` 是替换工作对保留人数、征询费用上限和最迟收件日的约定。`inquiries` 的每行是受托方可做的统计，`precision` 表示覆盖真实人数的连续整数区间宽度上限，而非预告返回哪个区间；`cost` 由单独的征询预算支付，不能替代实际席位。`returns` 是某次真实来件，不是自动随着征询选项发生；`known` 是收到日期。两个共享结果可以结合已有共享资料比较，只有仍不能确定未授权原子细分时才可并行发出；同一期间同组已共享结果见 `already_shared`。规划人员的报告不随共享处理而损失原始可授权证据。

## 读取与核对

使用 Python 3.11。
本地虚拟环境可按 `python3 -m pip install -r requirements.txt` 安装锁定的数值工具。有隔离运行环境时可直接使用已安装版本。

用 `python3 -m json.tool data/records.json` 查看原始记录。用 `python3 -m unittest discover -s tests -v` 核对演练资料的格式及关联，并核对业务分析结果。

## 业务分析

`coverplan` 包在输入核对之上提供业务分析。用 `python3 -m coverplan`（或 `python3 -m coverplan data/records.json`）打印分析报告；`coverplan.build_report(load_records(path))` 返回机器可读结果。

语义约定：

- 同一（分层, 期间）内，每个家庭按到访服务点子集落入一个 Venn 区域；全部有效凭证（撤回的除外）与已收到回件必须能由同一份区域构成解释，否则指出哪些凭证无法同时成立，不自行删除。不同期间没有可比观察窗，绝不合并求解。
- 独有覆盖、联合覆盖、改时段挤出数量都对全部相容构成取区间；同时停两站的缺口按停开集合的并集计算，两站重叠家庭一起失去服务。
- 请求的 `unique_floor` 是证据要求：须证明独有人数下界达到它，否则为证据不足。席位用于保住各层保底（`group_retained_minimum`）：保留人数 = 剩余服务点并集 + 已确认席位 + 实际可分配席位，须对全部相容构成成立。实际可分配席位不超过独有人数下界（联办方确认每席必接住一个尚未被承接的家庭），同一席位只被一个请求占用，历史耗用继续扣除。连最有利构成加全部剩余席位都够不到层保底的是席位不足；有利可达、不利不可达的是证据不足。已确认服务继续占用原席位；凭证撤回不自动取消服务，但被撤回的凭证不得支持新的承诺。
- 征询按已授权范围、约定精度（回件区间宽度上限）和到达时间返回；超过最迟收件日的不可期待。未收到的记缺回件，不算作零。比较征询方案时按可能回件枚举判定：有的能辨清单个站可办，有的无论返回什么都不改变决定；多份征询的回答必须联合相容，不能拼几个各自有利的回答来声称可以承诺。
- 各点只可收自己的规划结果和获准共享的汇总。并行发出共享结果前核对：不得唯一确定任何未授权原子细分，也不得把仅授权规划的凭证推导为对外的确定人数。
